# React_pro

A React application that displays posts with pagination, delete functionality, and image modal features.

## Features

- Fetches posts from JSONPlaceholder API
- Displays 6 posts per page with pagination
- Delete post functionality with red cross button
- Image click opens full-size modal
- Loading screen on startup (5 seconds)
- Responsive grid layout

## Tech Stack

- React
- Vite
- Context API for state management

## Getting Started

1. Install dependencies:
```
bash
npm install
```

2. Run development server:
```
bash
npm run dev
```

3. Build for production:
```
bash
npm run build
```
